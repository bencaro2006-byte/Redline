# Redline Optimizer

A free, open-source Windows optimizer for gaming PCs, in the spirit of Hone, with one difference:
every change is documented, shown to you before it happens, backed up, and reversible.

- **System Scan**: reads your hardware and Windows setup (read-only) and explains what it finds,
  for example why RAM rated 3200 runs at 2400 on some motherboards, or when your system drive is nearly full.
- **61 optimizations**: power plan, CPU scheduling, GPU, gaming, input, visual, network, storage,
  privacy, services and debloat. Each one lists exactly which settings it changes, what to expect,
  its side effects and the Microsoft documentation it is based on.
- **Debloat**: remove preinstalled Store apps (reinstallable from the Store); core Windows
  components are protected and never offered.
- **Games**: per-game high-performance GPU, fullscreen optimizations and CPU priority.
- **Backups**: every value is recorded before it changes. Revert one change or everything, and
  optionally create a Windows restore point before each batch.
- **Dry run**: preview what each change would do without writing anything.
- **Live monitor**: CPU load and clock, memory, GPU load and video memory.

## Download

Get the installer from the [Releases page](https://github.com/bencaro2006-byte/Redline/releases):
`redline-optimizer-<version>-setup-x64.exe`. The release notes list its SHA-256 checksum.

**Requirements:** Windows 10 version 2004 or later (64-bit). The catalog was researched and
verified on Windows 10 22H2. Windows 11 should work but has not been tested.

## Install

1. Run the setup file. Windows asks "Do you want to allow this app to make changes?": click **Yes**.
2. The installer is not code-signed, so SmartScreen may say "Windows protected your PC".
   Click **More info**, then **Run anyway**.
3. Redline installs to `C:\Program Files\Redline Optimizer`. It needs administrator rights on every
   start because it changes system settings, and it refuses to run from any other folder.

## Use

1. Optional: in **Settings**, turn on **Dry run** to preview everything first.
2. **Dashboard** › **Apply recommended**, or open **Optimizations**, switch on what you want, then
   **Review & apply**. Read the list of changes and click **Apply changes**. Restart if asked.
3. **Games**: open the NVIDIA checklist, and add each game's `.exe` to set its options.
4. **Backups**: undo any change, or **Revert all Redline changes**.

Changes are permanent Windows settings: you do not need to keep Redline running. Large Windows updates
or driver reinstalls can reset a few of them; the Dashboard shows anything that is no longer active.

**Before uninstalling**, use **Backups › Revert all Redline changes** if you want your old settings
back. Uninstalling the app does not undo the tweaks by itself.

## What it will never do

No kernel drivers and no CPU voltage or clock control. Nothing that weakens security: Redline never
disables Defender, Windows Update, UAC, the firewall, SmartScreen or CPU security mitigations
(a test enforces this). The Debloat screen lists the popular "optimizer" tweaks it leaves out, and why.

## Honest expectations

Most Windows tweaks have a small effect on their own, and the catalog says so: most are rated
low impact. Bigger wins usually come from in-game settings, GPU driver settings (see the NVIDIA
checklist) and keeping enough free space on your system drive. The optimization score measures how
many recommendations are in place, not FPS.

The catalog was researched on one gaming PC (Intel Core i7-7700, GeForce GTX 1070, Windows 10 22H2),
so some explanations mention that machine. Redline reads the real state of your own PC and marks
tweaks that don't apply to it.

## Build from source

Requires Node.js 22.12+ and npm on Windows.

```
npm ci
npm run dev        # Electron with hot reload (not elevated: read-only, dry run on)
npm run dev:web    # renderer only, in a browser, with sample data
npm test           # vitest
npm run typecheck
npm run ps-smoke   # read-only PowerShell check against your PC (dry-run only)
npm run dist       # NSIS installer in release/<version>/
```

`npm run catalog` rebuilds the catalog from `research/`. Script checksums are regenerated by every
build (`npm run hash-scripts`), and a test fails if they are stale.

## Project layout

| Path | What |
|---|---|
| `src/main/` | Electron main process: IPC (zod-validated), engine, scan, monitor, games, appx, settings |
| `src/main/catalog/catalog.json` | The tweak catalog (built from `research/`), validated at startup |
| `resources/scripts/` | Windows PowerShell 5.1 scripts; JSON on stdin, one JSON line on stdout |
| `src/preload/` | Sandboxed bridge: one function per capability (`window.redline`) |
| `src/renderer/` | React UI (design mockups in `design/project/*.dc.html`) |
| `research/` | Verified tweak research and toolchain notes |
| `docs/ARCHITECTURE.md` | How it fits together, and the security hardening |

Settings, backups and logs are stored in `%APPDATA%\Redline Optimizer`.

## Known limitations

- Per-user settings (input, visual, privacy, game GPU preference) are written to the account that
  approved the UAC prompt. If you elevate with a different administrator account, they land in
  that account's profile.
- Turning a game's CPU priority off leaves an empty `PerfOptions` key under Image File Execution
  Options (harmless).
- The installer is not code-signed, and Electron's asar-integrity fuse is not enabled yet.
